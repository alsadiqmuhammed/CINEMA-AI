# سوگ — متجر إلكتروني مؤتمت بالذكاء الاصطناعي

متجر إلكتروني عربي للسوق العراقي (الدينار العراقي، والدفع عند الاستلام، وأرقام 07XX) يشتغل بأقل تدخل بشري. الأتمتة والذكاء الاصطناعي يسوّون الشغل المتكرر، والقرارات الحساسة تبقى بيد الفريق: المدفوعات، والاسترجاع، والنشر النهائي، والإعلانات المدفوعة.

هذي **المرحلة الأولى**. الخطة الكاملة والمعمارية في [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).

## وش فيه

| الجزء | الموجود |
|---|---|
| **المتجر** | واجهة عربية RTL تشتغل على الجوال والكمبيوتر. فيه صفحات منتجات بـ SEO (عنوان ووصف وبيانات Product منظمة وخريطة موقع)، وبحث ذكي يتجاهل كلمات المحادثة مثل «أريد» و«عدكم»، واقتراح منتجات مكملة وبديلة، وسلة، وإتمام طلب (دفع عند الاستلام، أو تحويل بنكي إذا فعّلته)، وتتبع الطلب برقم الطلب والهاتف |
| **مساعد المحادثة** | يشتغل على الموقع وواتساب. يجاوب من الكتالوج والسياسات بس، ويقترح منتجات، ويسوي رابط طلب جاهز، ويحفظ بيانات العميل في الـ CRM، ويصنّف المحادثة (مهتم، محتمل، طلب مؤكد، متابعة، شكوى). وأي حالة حساسة يحوّلها لموظف فوراً |
| **الـ CRM** | ملف لكل عميل فيه طلباته ومحادثاته وسجل متابعته، وشرائح جاهزة (مهمون، متكررون، غير نشطين، موافقون على التسويق) |
| **الأتمتة** | تذكير السلة المتروكة، وطلب تقييم بعد التسليم، وتنبيهات نقص المخزون وتأخر الطلبات وفشل الدفع والشكاوى والعملاء المهمين |
| **المحتوى والتسويق** | مسودات لوصف المنتج والـ SEO والأسئلة الشائعة، واقتراح حملات إعلانية (الجمهور والنصوص والتصاميم والميزانية)، ورسائل جماعية للموافقين على التسويق. **كلها تنتظر موافقة قبل ما تنطبق** |
| **لوحة التحكم** | لوحة أداء، وطلبات، ومنتجات بصورها، وعملاء، وصندوق محادثات تقدر تستلم منه المحادثة من المساعد، وموافقات، وتنبيهات، ورسائل صادرة، وإعدادات، ومستخدمون |
| **الحماية والتدقيق** | ثلاث صلاحيات (مالك، مدير، موظف)، وحماية CSRF، وجلسات آمنة، و**سجل تدقيق** يوضح منو سوّى كل إجراء (موظف أو المساعد الذكي أو الأتمتة) ومتى وليش |

## النشر على الإنترنت (Render)

هاي الطريقة تطلعلك رابط حقيقي تفتحه من أي مكان. المشروع جاهز للنشر بملف `render.yaml`.

1. سوّي حساب على [render.com](https://render.com) وسجّل دخول بحساب GitHub مالتك.
2. من لوحة Render اختار **New → Blueprint**، واختار مستودع `CINEMA-AI`.
3. Render راح يطلب ثلاث قيم:
   - `ADMIN_EMAIL`: بريدك، وتدخل بيه للوحة التحكم.
   - `ADMIN_PASSWORD`: كلمة سر قوية، 10 أحرف على الأقل.
   - `ANTHROPIC_API_KEY`: مفتاح Claude. إذا تركته فارغ يشتغل المساعد بالردود البسيطة.
4. اضغط **Apply** وانتظر الإنشاء، ياخذ تقريباً 5 دقايق.
5. الرابط يطلع فوق بصفحة الخدمة، بشكل `https://soug-store.onrender.com` (أو اسم قريب منه). ولوحة التحكم على نفس الرابط وبآخره `/admin`.

**ملاحظات على الخطة المجانية:**
- الموقع ينام إذا محد دخله 15 دقيقة، وأول فتحة بعدها تاخذ تقريباً دقيقة. والخطة المدفوعة (Starter) تشيل هذا التأخير.
- قاعدة البيانات المجانية بـ Render **تنتهي بعد 30 يوم**. قبل الإطلاق الفعلي، رقّيها لخطة مدفوعة أو انقلها لمزود ثاني مثل Neon.
- الصور تنحفظ داخل قاعدة البيانات، فما تضيع لما يتحدث الموقع.
- المنتجات التجريبية تطلع حتى تشوف المتجر مليان. لما تضيف منتجاتك، أرشف التجريبية من لوحة التحكم، وغيّر `SEED_DEMO_CATALOG` إلى `false`.
- أي تعديل ينرفع على فرع `main` ينشر تلقائياً.

## النشر على Vercel (بدون بطاقة)

Render يطلب بطاقة ائتمان حتى للخطة المجانية. Vercel ما يطلب، والمشروع جاهز له بملف `vercel.json` ومدخل `api/index.js`.

1. سوّي قاعدة بيانات مجانية على [neon.tech](https://neon.tech) بمنطقة فرانكفورت، وانسخ الـ connection string.
2. سجّل دخول بـ [vercel.com](https://vercel.com) بحساب GitHub، واختار **Add New → Project**، واختار مستودع `CINEMA-AI`.
3. ضيف المتغيرات (Environment Variables):
   - `DATABASE_URL`: رابط Neon، و`DATABASE_SSL`: `require`
   - `ADMIN_EMAIL` و`ADMIN_PASSWORD` و`ANTHROPIC_API_KEY`: نفس شرح Render فوق.
   - `APP_SECRET`: 32 حرف عشوائي أو أكثر (`openssl rand -hex 32`).
   - `CRON_SECRET`: نص عشوائي، يحمي رابط الأتمتة اليومي.
   - `NODE_ENV`: `production`، و`DEFAULT_COUNTRY_CODE`: `964`، و`SEED_DEMO_CATALOG`: `true`.
4. اضغط **Deploy**. تحديثات الجداول (migrations) تنطبق وقت البناء قبل ما تشتغل النسخة الجديدة، وإذا فشلت يفشل البناء وتبقى النسخة القديمة شغّالة. حساب المالك ينبني مع أول زيارة.

**الفرق عن Render:**
- الأتمتة (تذكير السلة، طلب التقييم، التنبيهات) تشتغل **مرة باليوم** الساعة 10 الصبح بتوقيت بغداد، لأن الخطة المجانية بـ Vercel تسمح بـ Cron يومي بس. على Render تشتغل كل 5 دقايق.
- Vercel يقبل طلبات لحد 4.5 ميغا تقريباً، فالصورة الأكبر من هيچ ما تنرفع.
- قاعدة Neon المجانية ما تنتهي.

## التشغيل محلياً

يحتاج Node.js 22 أو أحدث، و PostgreSQL 14 أو أحدث.

```bash
npm install
cp .env.example .env              # عدّل DATABASE_URL على الأقل
npm run seed                      # ينشئ الجداول وبيانات تجريبية
npm start
```

بعدها افتح:
- المتجر: http://localhost:3000
- لوحة التحكم: http://localhost:3000/admin

| الحساب التجريبي | البريد | كلمة المرور |
|---|---|---|
| مالك | `owner@store.local` | `Demo-Owner-2026` |
| موظف | `staff@store.local` | `Demo-Staff-2026` |

الحسابات والبيانات التجريبية تنضاف بس خارج بيئة الإنتاج. في الإنتاج يتسوّى حساب المالك من `ADMIN_EMAIL` و `ADMIN_PASSWORD`.

أو بـ Docker:

```bash
docker compose up -d --build
docker compose exec app node src/db/seed.js
```

## التكاملات

كل تكامل يتفعّل لما تحط متغيراته. وإذا تركته فاضي يشتغل المتجر بدونه.

**Claude (الذكاء الاصطناعي):** حط `ANTHROPIC_API_KEY` وتتفعّل المحادثة الذكية وكتابة المحتوى بنموذج `claude-opus-5-5`. والطلبات تمشي مع ميزة التحويل التلقائي لنموذج بديل إذا رُفض الطلب، عن طريق `fallbacks`. بدون مفتاح، المساعد يرد بقواعد كلمات مفتاحية والمحتوى ينكتب من قوالب.

**واتساب (WhatsApp Business Cloud API الرسمي):**
1. سوِّ تطبيق في Meta for Developers وأضف له WhatsApp.
2. حط `WHATSAPP_TOKEN` و `WHATSAPP_PHONE_NUMBER_ID` و `WHATSAPP_APP_SECRET`، واختر `WHATSAPP_VERIFY_TOKEN` بنفسك.
3. اربط الـ Webhook على `https://your-domain/webhooks/whatsapp`، واشترك في `messages`.
4. للرسايل اللي تطلع بعد 24 ساعة من آخر رسالة للعميل، مثل تذكير السلة وطلب التقييم، سوِّ قوالب واعتمدها من Meta وحط أسماءها في `WHATSAPP_TEMPLATE_*`.

## الاختبارات

```bash
npm test     # يحتاج PostgreSQL، ويستخدم قاعدة store_test
```

فيه 22 اختبار تغطي:
- الشراء وخصم المخزون، ومنع بيع آخر قطعة مرتين لما يطلبها عميلين بنفس اللحظة.
- الصلاحيات و CSRF.
- مسار الموافقات والاسترجاع.
- تحويل المحادثة لموظف.
- الأتمتة واستقبال رسايل واتساب بدون تكرار.
- حلقة أدوات Claude ضد خادم API وهمي.

## هيكل المشروع

```text
src/
├── server.js            خادم HTTP
├── config.js            الإعدادات من متغيرات البيئة
├── db/                  الاتصال بقاعدة البيانات، والجداول (migrations)، والبيانات التجريبية
├── services/            منطق العمل: المنتجات، السلة، الطلبات، العملاء، المحادثات، الموافقات، التنبيهات
├── ai/                  مساعد المحادثة (أدوات Claude) وكتابة المحتوى
├── channels/            قنوات الإرسال (واتساب الآن، وماسنجر وانستقرام بالمرحلة الثانية)
├── automation/          المهام الدورية
├── routes/              المتجر، لوحة التحكم، API المحادثة، Webhooks
└── views/               صفحات HTML
public/                  CSS وأداة المحادثة
test/                    الاختبارات
```
